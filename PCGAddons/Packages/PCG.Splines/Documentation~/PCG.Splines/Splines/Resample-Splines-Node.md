# ResampleSplinesNode

Resamples each input spline into evenly spaced knots along its length.
The spacing between knots is defined by Step.

## Inputs

### Splines

The input list of splines to resample.

### Step

The distance between resampled knots along the spline. Smaller values produce denser, smoother splines.

## Outputs

### Results

The output list of resampled splines.
