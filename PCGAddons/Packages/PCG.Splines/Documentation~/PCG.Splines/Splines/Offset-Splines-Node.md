# OffsetSplinesNode

Offsets each input spline sideways by a fixed distance, perpendicular to its direction.
The offset direction is computed using the Up axis.

## Inputs

### Splines

The input list of splines to offset.

### Offset

The sideways distance to move the spline. Negative values offset to the opposite side.

### Up

The up axis used to compute the perpendicular offset direction.

## Outputs

### Results

The output list of offset splines.
