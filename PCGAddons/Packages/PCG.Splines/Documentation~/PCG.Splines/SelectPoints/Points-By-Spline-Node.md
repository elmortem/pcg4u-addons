# PointsBySplineNode

Filters points by whether they lie inside or outside closed splines.
Points inside closed splines go to Results; others go to Outsides.

## Inputs

### Points

Input points to test against spline boundaries.

### Splines

Closed splines defining inside/outside regions.

## Outputs

### Outsides

Points outside all closed splines.

### Results

Points inside any closed spline.
