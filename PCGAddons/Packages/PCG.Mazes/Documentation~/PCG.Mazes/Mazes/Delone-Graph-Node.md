# DeloneGraphNode

Generates a Delaunay triangulation graph from input points.

## Inputs

### MinDistance

The minimum distance between points in the triangulation.

### MinRatio

The minimum ratio between the shortest and longest edges of a triangle.

### Points

The input list of points to process.

## Outputs

### CenterPoints

The list of center points of the triangles in the graph.

### Result

The resulting Delaunay triangulation graph.
