# RegionSet

A set of 2D regions in the XZ plane. Each region is a filled polygon (outer contour minus holes). The whole set flows between Polygons nodes as a single value and carries named attributes per region.

## Properties

### Regions

The polygons that make up the set.

### PlaneY

World height (Y) at which the flat regions are placed.

### Attributes

Named attribute rows, one per region.

### Count

Number of regions in the set.
