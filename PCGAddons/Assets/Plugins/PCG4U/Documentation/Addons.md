## Addons

PCG4U can be extended with optional addon packages. Each addon is a separate UPM package, installed via the Unity Package Manager (Add package from git URL). Documentation for each addon ships inside its package (the `Documentation~` folder) and is available online via the package's documentation link.

## Available addons

* **PCG4U Splines** (`com.elmortem.pcg.splines`) - create, modify and sample Unity Splines; place and filter points along splines.
* **PCG4U Mazes** (`com.elmortem.pcg.mazes`) - graph and maze generation (grid, Delaunay, MST) and conversion to splines.
* **PCG4U SpriteShapes** (`com.elmortem.pcg.spriteshapes`) - 2D SpriteShape instancing.
* **PCG4U BRG** (`com.elmortem.pcg.brg`) - BatchRendererGroup rendering of instances.
* **PCG4U Octree** (`com.elmortem.pcg.octree`) - octree-accelerated spatial point queries.

## Installation

Open Window > Package Manager, choose "Add package from git URL...", and paste the addon's Git URL.
