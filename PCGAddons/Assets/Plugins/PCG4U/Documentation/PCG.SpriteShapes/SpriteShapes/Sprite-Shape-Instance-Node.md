# SpriteShapeInstanceNode

Generates SpriteShape instances from input splines with configurable sprite shape profile and height.

## Inputs

### Height

Height scaling factor for sprite shape.

### Name

GameObject name for generated sprite shape instances.

### Splines

Input splines to convert into sprite shapes.

### SpriteShape

SpriteShape profile to apply.

## Variables

### Enabled

Enables or disables generation.

## Outputs

### Results

Output sprite shape instance data.
