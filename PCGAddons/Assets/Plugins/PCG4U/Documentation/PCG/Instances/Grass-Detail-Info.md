# GrassDetailInfo

Configuration data for terrain grass/detail layer prototypes.

## Variables

### AlignToGround

How much grass aligns to terrain slope (0 = upright, 1 = full align).

### Density

Grass density per square meter.

### DetailPrefab

Grass detail prefab (3D mesh).

### DetailTexture

Grass detail texture (billboard).

### DryColor

Dry grass color.

### HealthyColor

Healthy grass color.

### MaxHeight

Maximum grass height.

### MaxLayerDensity

Maximum grass instances per detail layer.

### MaxWidth

Maximum grass width.

### MinHeight

Minimum grass height.

### MinWidth

Minimum grass width.

### NoiseSeed

Seed for procedural variation noise.

### NoiseSpread

Noise frequency for procedural variation.

### PositionJitter

Random position offset magnitude.

### Radius

Grass patch radius.

### RenderMode

Grass rendering mode.

### UseDensityScaling

If true, density varies based on distance.

### Weight

Weight for random selection.
