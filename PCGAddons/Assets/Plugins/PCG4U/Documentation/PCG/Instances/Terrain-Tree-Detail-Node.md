# TerrainTreeDetailNode

A node that generates terrain details instances based on input points and a terrain detail info (Terrain.AddTreePrototype).

## Inputs

### Points

List of points through the Points input port

### Seed

Seed value for randomization

## Variables

### DetailInfo

Terrain tree detail info.

### Enabled

Indicating if the node is enabled

## Outputs

### Results

Outputs the generated Terrain Tree Detail instances through the Results output port
