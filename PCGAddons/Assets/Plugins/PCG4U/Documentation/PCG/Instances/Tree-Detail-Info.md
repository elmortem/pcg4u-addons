# TreeDetailInfo

Configuration data for terrain tree prototypes.

## Variables

### BendFactor

Wind bend sensitivity factor.

### DryColor

Color for dry/dead trees.

### HealthyColor

Color for healthy trees.

### MaxHeight

Maximum random height.

### MaxWidth

Maximum random width.

### MinHeight

Minimum random height.

### MinWidth

Minimum random width.

### Prefab

Tree prefab to place.

### Weight

Weight for random selection.
