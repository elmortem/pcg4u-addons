# PointsToVector3Node

Converts input points to a single Vector3 according to the selected mode.

## Inputs

### Index

Index used in Index mode.

### Points

Input list(s) of points to convert.

### Seed

Seed for deterministic Random mode. Use 0 or less for non-deterministic behavior — a random seed is generated and stored on bind.

## Variables

### Mode

Conversion mode used to derive the resulting Vector3.

## Outputs

### Result

Output vector after applying the selected mode.
