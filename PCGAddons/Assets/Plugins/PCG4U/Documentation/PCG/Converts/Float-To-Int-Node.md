# FloatToIntNode

Converts a float to an int using the selected rounding mode.

## Inputs

### Value

Source float value.

## Variables

### Mode

Rounding mode applied to `Value`:
- Round: nearest integer
- Floor: largest integer not greater than `Value`
- Ceil: smallest integer not less than `Value`

## Outputs

### Result

Integer representation of `Value` according to `Mode`.
