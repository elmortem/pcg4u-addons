# ChangeDensityNode

Changes the density of input points based on specified parameters.
This node allows for modifying the density of points using different modes and random values within a given range.

## Inputs

### Max

The maximum value for the density change.

### Min

The minimum value for the density change.

### Points

The input list of points to process.

### Seed

The seed for random number generation.

## Variables

### Mode

Determines how the density change is applied to the points.

## Outputs

### Results

The processed list of points with updated densities.
