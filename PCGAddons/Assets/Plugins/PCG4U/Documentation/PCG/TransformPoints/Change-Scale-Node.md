# ChangeScaleNode

Changes the scale of input points based on specified parameters.
This node allows for modifying the scale of points using different modes and random values within a given range.

## Inputs

### Max

The maximum value for the scale change.

### Min

The minimum value for the scale change.

### Points

The input list of points to process.

### Seed

The seed for random number generation.

## Variables

### Mode

Determines how the scale change is applied to the points.

## Outputs

### Results

The processed list of points with updated scales.
