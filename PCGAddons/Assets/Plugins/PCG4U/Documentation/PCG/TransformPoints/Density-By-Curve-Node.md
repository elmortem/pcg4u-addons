# DensityByCurveNode

Generates density values for input points based on their distance from a central point, using a customizable curve.
This node allows for creating gradient-like density distributions across a set of points, with control over the distribution shape and axes.

## Inputs

### Points

The input list of points to process.

### RadiusMult

A multiplier for the effective radius of the density distribution.

## Variables

### Axes

Determines which axes are used for distance calculation.

### Curve

Defines the relationship between distance and density value.

## Outputs

### Results

The processed list of points with updated density values.
