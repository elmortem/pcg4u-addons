# DensityRandomNode

Assigns random density [0,1] to each input point. Optional seed enables deterministic output.

## Inputs

### Points

Input points to receive random density.

## Variables

### Seed

Seed for deterministic randomness. Use 0 or less for non-deterministic behavior — a random seed is generated and stored on bind.

## Outputs

### Results

Output points with randomized density values.
