# ChangePositionNode

Changes the positions of input points based on specified parameters.
This node allows for modifying the positions of points using different modes and random values within a given range.

## Inputs

### Max

The maximum values for the position change.

### Min

The minimum values for the position change.

### Points

The input list of points to process.

### Seed

The seed for random number generation.

## Variables

### ApplyToGroup

Determines whether to apply the change to each group of points separately.

### Mode

Determines how the position change is applied to the points.

## Outputs

### Results

The processed list of points with updated positions.
