# ChangeNormalNode

Changes the normals of input points based on specified parameters.
This node allows for modifying the normals of points using different modes and random values within a given range.

## Inputs

### AmountMax

The maximum amount of change to apply to normals.

### AmountMin

The minimum amount of change to apply to normals.

### DirectionMax

The maximum direction vector for normal changes.

### DirectionMin

The minimum direction vector for normal changes.

### Points

The input list of points to process.

### Seed

The seed for random number generation.

## Variables

### Mode

Determines how the normal change is applied to the points.

## Outputs

### Results

The processed list of points with updated normals.
