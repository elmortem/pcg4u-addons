# ChangeAngleNode

Changes the angles of input points based on specified parameters.
This node allows for modifying the angles of points using different modes and random values within a given range.

## Inputs

### Max

The maximum value for the angle change.

### Min

The minimum value for the angle change.

### Points

The input list of points to process.

### Seed

The seed for random number generation.

## Variables

### Mode

Determines how the angle change is applied to the points.

## Outputs

### Results

The processed list of points with updated angles.
