# LerpNode

Linearly interpolates between two float values.

## Inputs

### A

Start value.

### B

End value.

### T

Interpolation factor.

## Variables

### Clamp

When enabled, `T` is clamped to [0, 1]; otherwise extrapolation is allowed.

## Outputs

### Result

Interpolated value between `A` and `B` by `T`.
