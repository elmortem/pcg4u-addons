# Vector3LerpNode

Linearly interpolates between two Vector3 values.

## Inputs

### A

Start vector.

### B

End vector.

### T

Interpolation factor.

## Variables

### Clamp

When enabled, `T` is clamped to [0, 1]; otherwise extrapolation is allowed.

## Outputs

### Result

Interpolated vector between `A` and `B` by `T`.
