# Baseline точек ДО миграции на PcgPointCloud

Снято через `unity-bridge` на 2026-07-25, до любых правок кода (Unit 0 ТДД `260725-2051-TDD-addons_point_cloud_migration.md`).

Метод: для каждого `PcgComponent` на сцене создан отдельный `PcgExecGraph`, привязан к `component.GraphData`/`component.GraphId`, все executor'ы (включая вложенные через `SubGraphNodeExecutor.Inner`, рекурсивно) прогнаны через `PcgComputeSystem.ResolveAsync`. Для каждого executor'а, реализующего `IPointsCount`, выведена строка `<GraphIdPath>|<NodeTitle>|<NodeType>|<PointsCount>`, где `GraphIdPath` — путь по вложенным сабграфам через `>`. Формат строки: `<GraphIdPath>|<NodeTitle>|<NodeType>|<PointsCount>` или `<GraphIdPath>|<NodeTitle>|<NodeType>|Attributes:<col1>,<col2>,...`.
