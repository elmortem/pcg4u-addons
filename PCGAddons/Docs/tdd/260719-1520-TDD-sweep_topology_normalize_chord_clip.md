# Sweep — нормализация топологии, удаление разведения углов, клип хорд плиты — Agent Execution Spec

Инкремент поверх `260719-1416-TDD-sweep_junction_corner_separation.md`. Диагноз подтверждён численно на реальной сцене (`SweepDemoScene`): открытый сплайн начинается на замкнутой петле, реальная топология даёт кусок 0.06 м (чуть выше `MinPieceLength`), оба его конца прицепляются к одному junction, и оба его рукава встают в центр плиты; `SeparateCorners` вокруг таких вырожденных рукавов не сходится никогда и раздувает setback соседей до десятков метров (в сцене — 38–77 м) — плита на полкарты, съеденные ленты. Механизм разведения углов признан негодным и удаляется целиком. Вместо него: нормализация топологии до сплита (микро-куски исключаются, junction'ы ближе порога сливаются), митровые setback'и с капом остаются как в плитном ТДД, а остаточный перехлёст углов соседних рукавов на острых пересечениях снимается в билдере геометрически — клипом хорд по точке их пересечения. Решения проверены офлайн-прототипом на данных сцены: плиты компактны, ленты целы, острый крест 10° даёт простой контур без «бабочек».

## Foundations (shared, used across units)

- Порог нормализации: `normalizeThreshold = math.max(step, lateralExtent)`, где `step` и `lateralExtent` — те же значения, что уже передаются в `BuildNetwork`.
- Кусок топологии сплайна `i`: интервал между соседними по `Distance` резами этого сплайна (закрытый сплайн — с враппом через `Length`, длина замыкающего куска = `Length - lastDistance + firstDistance`); крайние куски открытого сплайна — от начала до первого реза и от последнего реза до конца.
- Принадлежность реза junction'у — только поле `SplineCut.JunctionIndex`, без геометрического поиска.
- Клип пары: для соседних рукавов `k`, `kb` и этажа листа хорда рукава — плановый отрезок от CW-угловой кольцевой вершины этажа до CCW-угловой. Перехлёст: `NormalizeSigned(phiCw(kb) - phiCcw(k)) < 0.01f`, где `phi*` — плановые азимуты угловых вершин этажа от центра. Точка клипа `P` — пересечение хорд как отрезков (существующая математика `RaySegment` не переиспользуется: прямой segment-segment тест, знаменатель `< 1e-12f` — пересечения нет). Параметры пересечения: `s` вдоль хорды `k`, `u` вдоль хорды `kb`, оба в `[0..1]`.
- Позиция вершины клипа: `pos = lerp(posCw_k, posCcw_k, s)` по 3D-позициям концов хорды `k`, `rv = lerp(rvCw_k, rvCcw_k, s)`.

## Execution Plan

Units run in listed order.

### Unit 1 — Солвер: нормализация топологии, удаление разведения

- Goal: `SeparateCorners` удалён; перед сплитом топология нормализуется: микро-куски исключены, близкие junction'ы слиты; setback'и нигде не превышают митровый кап.
- Touch:
  - `SweepNetworkSolver.cs` — удалить `SeparateCorners`, `CornerAzimuths`, `SortByAzimuth`, `CornerVertex`, константу `MinCornerGap`, поля `ArmWork`, используемые только ими; добавить `internal static SplineNetworkTopology NormalizeTopology(SplineNetworkTopology topology, SplineSnapshot[] snapshots, float step, float lateralExtent)`.
  - `SweepSplineNodeExecutor.cs` — в сетевом пути вызывать `NormalizeTopology` перед `SolveSplit` (в пуле, рядом с ним) и дальше везде использовать нормализованную копию (сплит, `BuildNetwork`, окно террейна). `GetVersionSalt` не меняется (хеш считается от входной топологии).
- How:
  - `NormalizeTopology`: глубокая копия списков `Junctions` и `Cuts`. Цикл до стабилизации, максимум 16 итераций:
    - сгруппировать резы по `SplineIndex`, отсортировать по `Distance`;
    - найти первый кусок короче `normalizeThreshold` в детерминированном порядке (по `SplineIndex`, затем по `Distance` начала куска) среди кусков вида «рез—рез» и крайних «начало—рез»/«рез—конец» открытых сплайнов; куски без резов пропускаются;
    - крайний кусок открытого сплайна — удалить его единственный рез;
    - кусок «рез—рез» с одинаковым `JunctionIndex` обоих резов — удалить рез с большей `Distance` (замыкающий кусок закрытого сплайна — рез с большей `Distance` из пары);
    - кусок «рез—рез» с разными `JunctionIndex` `a < b` — junction `a` получает `Position = (Pa + Pb) * 0.5f`, `Valency = Va + Vb - 2`; junction `b` удаляется из списка; во всех резах `JunctionIndex == b` заменяется на `a`, индексы больше `b` уменьшаются на 1; рез куска с большей `Distance` удаляется;
    - после каждого изменения — следующая итерация цикла.
  - Блок absorb (`remain < step`) и всё остальное в `BuildNetwork` — без изменений; вызов `SeparateCorners` удалить.
- Gate: bridge-задача `Task_SweepN_U1` (Rectangle `w = 4`, `h = 0.5`, `lateralExtent = sqrt(4 + 0.25) ≈ 2.0616`, `Step = 1`, `MaxAngle = 5`, `SetbackScale = 1`, без террейна; топологии собираются руками с корректными `JunctionIndex`):
  - S1 — микро-кромка: прямая A 60 м `(0,0,0)-(60,0,0)`, прямая B 30 м из `(30,0,0.06)` вверх по Z, пересекающая A у своего начала; топология: junction в `(30,0,0)`, рез A на 30, рез B на 0.06: `PASS microcut` — после `NormalizeTopology` реза на B нет, junction один; `PASS microarms` — после `BuildNetwork` у junction ровно 3 рукава и все их setback ≤ `2.5 * 2.0616 * 1.01`.
  - S2 — мост: A `(0,0,0)-(60,0,0)`, B `(0,0,1)-(60,0,1)`, C `(30,0,-30)-(30,0,30)`; топология: два junction `(30,0,0)` и `(30,0,1)`, резы A@30 (j0), B@30 (j1), C@30 (j0), C@31 (j1): `PASS merge` — после нормализации junction один с позицией `(30, 0, 0.5) ± 0.01`, у C один рез; `PASS mergearms` — `BuildNetwork` даёт одному junction 6 рукавов.
  - S3 — регрессия X-крест 90° (два прямых сплайна 60 м, пересечение в серединах): `PASS setback90` — setback всех рукавов `2.0616 ± 0.05`.
  - S4 — стаб 3 м (прямая 60 + ветка 33, пересекающая её в 30 м от начала ветки): `PASS stub` — стаб-кусок поглощён (`rangeEnd - rangeStart < 1e-4`), его рукав `Terminal == true`.
  - Рефлексией: метод `SeparateCorners` отсутствует в `SweepNetworkSolver` (`PASS nosep`); компиляция чистая, `foreign_errors: false`.
- On failure: ≤ 3 итерации на гейт, затем стоп и отчёт; не возвращать итеративный рост setback ни в каком виде; ассерты не менять.

### Unit 2 — Билдер: клип хорд перехлёстнутых пар

- Goal: контур листа прост даже при перехлёсте углов соседних рукавов; ленты перехлёстнутых пар не строятся.
- Touch: `SweepJunctionMeshBuilder.cs`.
- How:
  - Перед сборкой листов один раз на junction вычислить для каждой пары `(k, kb)` и каждого листа (верх/низ) перехлёст и клип по Foundations. Хорда рукава — от кольцевой вершины CW-колонки этажа листа до вершины CCW-колонки (этаж верхнего листа — верхние концы колонок, нижнего — нижние).
  - Сборка контура листа: для рукава `k` вершины цепочки эмитятся с фильтром: параметр вершины вдоль своей хорды (проекция на отрезок CW→CCW, 0..1) должен быть `> u` клипа пары `(k-1, k)` (если она клипнута) и `< s` клипа пары `(k, kb)` (если клипнута). После цепочки: пара клипнута — эмитится одна вершина `P` (позиция и `rv` по Foundations); не клипнута — кромка (rim) как сейчас. Перехлёст есть, но пересечения хорд нет — вершина `P` не эмитится, кромка тоже (цепочки соединяются напрямую).
  - Ленты (bands): для клипнутых пар не строятся; для остальных — как сейчас.
  - `CollapseColinear`, `TriangulateLoop`, terminal-крышки, подразбиение и хвост `Build` — без изменений.
- Gate: bridge-задача `Task_SweepN_U2` (профиль и параметры как в U1):
  - S5 — острый крест 10° (два прямых сплайна 120 м под 10°, пересечение в серединах): `PASS partitionSharp` — сетка 32×32 по верхнему листу: покрытие ≤ 1 (вне 1e-3 от рёбер); `PASS noflip` — у всех треугольников верхнего листа `dot(нормаль, up) > 0`; `PASS compactSharp` — все вершины плиты в плане не дальше `(maxSetback + 2.0616) * 1.3` от центра; `PASS cornersKept` — у каждого рукава не менее 2 из 4 угловых кольцевых вершин присутствуют в плите ≤ 1e-4.
  - S1 из U1 (микро-кромка) с построением плиты: `PASS microplate` — partition ≤ 1 и все вершины плиты ≤ `(2.5 * 2.0616 + 2.0616) * 1.2` от центра.
  - S3 регрессия 90°: `PASS top` (все треугольники `dot(нормаль, up) > 0.5` на `y = 0.5 ± 1e-3`), `PASS bottom` (симметрично `y = 0 ± 1e-3`), `PASS seams` (все 8 кольцевых вершин каждого рукава ≤ 1e-4), `PASS walls` (`|dot(нормаль, up)| ≤ 0.2` → наружная ориентация от центра), `PASS partition90`, `PASS nohole` (16 лучей из центра пересекают верхний лист).
  - `foreign_errors: false`.
- On failure: ≤ 3 итерации, затем стоп и отчёт; не удалять кольцевые вершины иначе как фильтром клипа; ассерты не менять.

### Unit 3 — Документация

- Goal: справка описывает нормализацию и поведение на острых пересечениях.
- Touch: `Packages/PCG.Sweep/Documentation~/Sweep-Addon.md` — в Behavior сетевого режима: перед сплитом топология нормализуется (куски короче `max(Step, полуширина профиля)` вливаются в соседей, перекрёстки ближе этого порога сливаются в один), setback митровый с капом 2.5 полуширины, на очень острых пересечениях плита обрезается по пересечению торцов и ленты могут коротко перекрываться по высоте — компромисс, регулируемый `Setback Scale`.
